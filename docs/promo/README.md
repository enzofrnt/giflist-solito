# Giftlist — promotional motion demo (web desktop)

- File: `docs/promo/giftlist-promo.mp4`
- Format: 1920×1080, **30 fps**, H.264 + AAC, **72 s**.
- Single continuous Playwright capture: onboarding → login → dashboard → create list → add gift → share → logout → public search → reserve without account.
- Slow visible custom cursor, click ripples, large animated lower-third titles and step counter.
- **No voiceover**; dynamic generated background music only.
- Demo accounts: see `docs/demo/README.md`.

## Storyboard

1. Arrival on the GiftList landing page.
2. Login with a fresh account.
3. Start from an empty dashboard (no pre-made lists).
4. Create the first list and add a gift with photo, price and description.
5. Share via link/QR code.
6. Log out: visitors do not need an account.
7. Search a friend’s public profile and discover their public list.
8. Reserve a gift without an account.
9. Closing: a free account is for creating lists and keeping favorites; reservations remain account-free.
