# Feature Specification: Reliable OpenGraph Cards for Shared Lists

**Feature Branch**: `008-list-og-preview`

**Created**: 2026-10-29

**Status**: Approved — implementation

**Input**: Shared list pages may not render useful social previews because the OG image came from the list’s remote image (sometimes blocked/missing). Google indexing is not the priority for private share links, but the OpenGraph card with list information is required.

## User Scenarios

### User Story 1 - Useful preview for a shared list (Priority: P1)

When someone pastes a `giftlist.fr/list/<code>` link into WhatsApp, iMessage, Slack, Discord or social media, the card shows the list title, description, owner, gift count and Giftlist branding.

**Acceptance Scenarios**:

1. **Given** a valid public share code, **When** the link is fetched, **Then** `og:title`, `og:description`, `og:url`, `og:image` (1200×630 PNG), `twitter:image` are present.
2. **Given** the list has no image or a blocked remote image, **Then** the OG image is generated by Giftlist and still renders.
3. **Given** an invalid share code, **Then** a generic Giftlist OG image is served, with no 500.
4. **Given** private share links, **Then** pages remain `noindex` but OG crawlers can still fetch the card.
5. **Given** a list with an unusually long title/description, **Then** the image truncates safely.

## Requirements

- **FR-001**: Add a dynamic `opengraph-image.tsx` for `/list/[shareCode]` using Next `ImageResponse`.
- **FR-002**: Query only public list fields (title, description, owner name, gift count); never expose email/reservation data.
- **FR-003**: Render 1200×630 with Giftlist logo, list title, description, owner, gift count.
- **FR-004**: Fall back to a generic card on missing list/DB error.
- **FR-005**: `generateMetadata` for list pages must point OG/Twitter to the dynamic image with dimensions/alt.
- **FR-006**: Keep list pages `noindex`; no SEO indexing change.
- **FR-007**: Add `logo-og.png` public asset.
- **FR-008**: Typecheck/build/route tests pass.

## Success Criteria

- OG image route returns PNG 1200×630 for invalid and valid codes.
- Shared-list metadata points to the dynamic image, not the raw list image.
- No 500 on missing list/DB failure.
- No private data in image or metadata.
